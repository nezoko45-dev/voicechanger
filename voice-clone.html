🎙 F5-TTS Voice Clone Studio

Testing the F5-TTS browser voice-cloning engine as the replacement for VoxShot/Kokoro.

Try F5-TTS now

The browser demo below runs F5-TTS locally on your device. Upload a short clean reference recording, provide its transcript, enter the text you want spoken, and generate audio.

Open F5-TTS voice cloning inside this extension ↗

If the bundled studio does not load on your browser, open the hosted demo instead.

The demo downloads its model files on first use. WebGPU-capable Chrome or Edge is recommended. Your reference recording is processed by the demo in your browser, not sent to a voice-generation server.

How to test it

  1. Open the demo and choose the single-speaker TTS mode.
  2. Upload a clean 5–10 second WAV/MP3 of a voice you own or have permission to use.
  3. Enter the exact words spoken in the reference clip.
  4. Type a new sentence, generate it, and listen to the similarity and quality.

About this extension build

The F5-TTS browser studio is bundled into this extension during the GitHub Actions build from the upstream open-source project. It uses a custom ONNX encoder/transformer/decoder pipeline and supporting tensor/audio code; it cannot be replaced by changing a model ID.

The F5-TTS studio runs inference in the browser using WebGPU/WASM. Model weights download on first use and are cached by the browser; first launch requires an internet connection.
