# Chrome c.ai Voice Bridge\n\nWindows self-contained app. Starts a local HTTP endpoint at `127.0.0.1:8765`, serves the included Chrome Web Speech page, and sends final transcripts to the focused c.ai edit field with Windows UI Automation.\n\nAfter submitting a transcript, the bridge watches for c.ai's Stop-generating control to disappear (or a Regenerate/Try again control to appear), then marks itself IDLE. Optional Voice-button keepalive runs only while IDLE.\n\nBuild: GitHub Actions workflow `Build Chrome c.ai Voice Bridge`; artifact `ChromeCaiBridge-win-x64`.\n\nClick the c.ai message box before recognition starts. Voice UI automation is experimental; verify the accessible control name before enabling it.\n
