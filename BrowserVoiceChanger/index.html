VoiceChanger

Resemble STT/TTS ready

Recognized speech

Press Connect, choose your custom Resemble voice, then start the voice changer.

How it works

Microphone → Resemble Speech-to-Text → your custom voice from the Resemble library → Resemble Text-to-Speech → Windows audio output. The old donor WAV / ElevenLabs conversion path is no longer used for live voice changing.

Audio routing

Set the Windows playback/output device used by this mod to your virtual audio cable, then select that cable as the microphone input in ChilloutVR.

Security

Your Resemble API key is stored locally by the bridge. Do not commit it to GitHub.
