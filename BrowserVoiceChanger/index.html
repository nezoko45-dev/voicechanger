How this version works

Source WAV → Resemble Speech-to-Speech → target voice → WAV → Windows audio output. Resemble currently expects the donor WAV to be reachable through a public HTTPS URL, so this first integration is WAV conversion rather than low-latency microphone streaming.

Security

The API key is stored only in the local Python config file and is never sent to the browser-hosting server. Do not commit your API key to GitHub.
