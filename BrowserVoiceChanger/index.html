VoiceChanger

Browser STT/TTS ready

Audio output

Choose CABLE Input as the browser output if you want the converted voice routed into VB-CABLE.

Recognized speech

Connect first, choose your custom Resemble voice, test the audio, then start automatic listening.

Hands-free mode

Microphone stays open while the voice changer is running. Speak normally; the browser detects the end of each sentence, automatically sends the captured WAV to Resemble STT, gets the text, sends it to Resemble TTS, plays the returned WAV, and immediately listens again. You do not press Stop between sentences.

ChilloutVR routing

Select CABLE Input as the browser output. Then select CABLE Output as your microphone/input inside ChilloutVR. This version does not start Python and does not use the old WinMM playback path.

Security

This is a client-side browser build. Your Resemble API key is kept in the page memory and is sent directly from your browser to Resemble. Do not commit the key to GitHub.
