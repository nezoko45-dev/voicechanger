How it works

Microphone → Resemble Speech-to-Text → your custom voice → Resemble Text-to-Speech → the selected Windows waveform output device. Automatic mode looks for a virtual audio cable first, then falls back to the Windows default output.

Audio routing

For ChilloutVR, leave Output device on Automatic if you use a virtual cable. The bridge detects the cable playback endpoint and sends the generated TTS WAV there. Then select the cable's recording/capture endpoint as your ChilloutVR microphone.

Security

Your Resemble API key is stored locally by the bridge. Do not commit it to GitHub.
