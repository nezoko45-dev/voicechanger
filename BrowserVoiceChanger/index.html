VoiceChanger

Cartesia browser STT/TTS ready

Audio output

Choose CABLE Input as the browser output if you want the converted voice routed into VB-CABLE.

Recognized speech

Enter your Cartesia API key and Voice ID, choose the output, test the audio, then start automatic listening.

Hands-free mode

Microphone stays open while the voice changer is running. Speak normally; the browser detects the end of each sentence, sends the captured WAV to Cartesia STT, gets the text, sends it to Cartesia TTS, plays the returned audio, and immediately listens again.

ChilloutVR routing

Select CABLE Input as the browser output. Then select CABLE Output as your microphone/input inside ChilloutVR. This version is browser-based and does not start Python or use the old WinMM playback path.

Security

Your Cartesia API key stays in this page's memory and is sent only to the local mod bridge to obtain a short-lived Cartesia access token. The browser uses that temporary token for STT/TTS. Do not commit your API key to GitHub.
