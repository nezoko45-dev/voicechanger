Audio output

The Resemble WAV is played by your browser Audio API. Choose CABLE Input here if you want the audio sent into VB-CABLE.

Recognized speech

Connect first, choose your custom Resemble voice, then test the audio.

New audio path

Microphone → Resemble Speech-to-Text → Resemble Audio/TTS API → WAV audio returned to this browser → browser output device. The old Python WinMM playback path is no longer used.

ChilloutVR routing

If you use VB-CABLE, select the playback endpoint named CABLE Input as the browser output. Then select CABLE Output as your microphone/input inside ChilloutVR. If you want to hear the converted voice yourself too, use a Windows monitoring/mixer setup; sending only to CABLE Input intentionally routes it into the virtual cable.

Security

Your Resemble API key is stored locally by the Python bridge. Do not commit the key to GitHub.
