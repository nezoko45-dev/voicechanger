Audio Repeater KS route

Browser TTS → selected virtual cable playback → Audio Repeater (Kernel Streaming) Wave In → Audio Repeater Wave Out → second virtual cable → ChilloutVR microphone.

Set Audio Repeater KS Wave In to the recording side of the virtual cable selected above. Set its Wave Out to the virtual cable you want ChilloutVR to receive. The browser only handles the UI, microphone STT, and Deepgram TTS; Audio Repeater handles the final low-latency audio hop.
