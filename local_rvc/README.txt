LOCAL WAV RVC

1. Run setup-local-rvc.bat once.
2. Put your target RVC .pth model into local_rvc\models.
3. Run local-wav-voicechanger.bat.
4. Drag a WAV onto the batch, or paste its path.
5. The converted WAV is written beside the source as converted_<name>.wav.

A matching .index in local_rvc\models or beside the .pth is used automatically.
