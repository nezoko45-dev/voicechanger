⚡ WebGPU Voice Converter

Experimental browser voice conversion. GPU inference is mandatory; this build never silently falls back to WASM.

Use an ONNX audio-to-audio voice model whose graph supports ONNX Runtime WebGPU. RVC models may expose multiple inputs and may require the full RVC pipeline.
WebGPU has not been tested yet.
Choose an ONNX model, then press START WEBGPU.
Architecture: microphone → WebGPU ONNX inference → Chrome audio player → selected Chrome output. Raw microphone audio is never played.
