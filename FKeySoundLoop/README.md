# F Key Sound Loop

A standalone Windows x64 app that loops a selected WAV or MP3 file while the F key is held.

## Use
1. Download and run `FKeySoundLoop.exe`.
2. Choose a `.wav` or `.mp3` file.
3. Hold **F** anywhere in Windows to play it in a continuous loop.
4. Release **F** to stop playback immediately.
5. Use **Test audio** to preview the selected file.

The app installs a global low-level keyboard hook, so F works even when another application is focused. The app does not intercept or block the key from other applications.
