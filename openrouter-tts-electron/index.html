OpenRouter TTS Reader

Standalone Windows desktop app. No Chrome tab, local helper EXE, or GitHub Pages connection required. Your API key stays in app memory and is sent to OpenRouter only when you generate speech.

Ready. Enter your API key, choose a voice and output device, then dictate or type text.

Microphone access is requested only when you press Start microphone dictation. Audio is played by the app and routed to the selected Windows output when supported.
