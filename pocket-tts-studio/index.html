PocketWebTools performs the voice cloning. This page cannot control another website's private controls directly, so the companion extension handles the transcription-to-generation loop there.

1
Open PocketWebTools Voice Cloning

Load your reference WAV into its reference voice/upload area and make sure the voice is ready.

2
Install the companion Chrome extension

Load extension/pocketweb-dictation as an unpacked extension from this repository.

3
Start transcription here

Press Start listening above. After each recognized phrase, this page sends the text into the TTS text field on your open PocketWebTools tab. Then press Generate Speech there when you are ready.

Open PocketWebTools ↗Extension files ↗

The companion extension is required because Chrome prevents one website from directly editing another website's fields. This page sends text only; it does not upload your WAV or automatically press Generate Speech. Only clone voices you own or have permission to use.
