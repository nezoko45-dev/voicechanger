Microsoft Edge Reader

Continuous browser dictation and text-to-speech. No executable, local server, or API key.

Ready. Press Start dictation and allow microphone access.

Dictation uses your browser's speech-recognition service. It automatically restarts after recognition sessions end and refreshes the session about every 50 seconds to keep it going.

Voice choices depend on voices installed or made available by Microsoft Edge and Windows. This page uses the browser's built-in speech synthesis; it does not call a paid TTS API.
