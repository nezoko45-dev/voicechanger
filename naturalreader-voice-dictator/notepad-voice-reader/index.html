OpenRouter TTS Reader

Paste a ChatGPT reply and generate spoken audio using OpenRouter. The Windows helper holds your OpenRouter API key; this page never asks for or stores the key.

Before starting: Run OpenRouterTTSHelper.exe, enter your OpenRouter API key in its console, and leave that window open. The key stays in the helper's memory and is not saved to disk.
Or click the text box and press Ctrl+V.

Start OpenRouterTTSHelper.exe, then paste a reply to read aloud.

Example voice IDs: Grok: eve, ara, rex, sal, leo. Voxtral: en_paul_neutral. MAI: en-US-Harper:MAI-Voice-2. Check OpenRouter's speech models for current compatibility.
