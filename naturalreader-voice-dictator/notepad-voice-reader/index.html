OpenAI Voice Dictation & Reader

Speak naturally and the AI will answer out loud using OpenAI's real-time voice model. It handles pauses and turn-taking, so this page does not need to detect ChatGPT webpage buttons or use browser text-to-speech.

Your key is saved in this browser only (local storage), not written into the GitHub JavaScript file. The backend uses it to mint a short-lived voice token. Anyone with access to this browser profile can access the saved key; use a dedicated API key with usage limits. The backend must be deployed once.
