Seed-VC Speech-to-Speech

Real-time voice conversion — your microphone speech is converted into the selected reference voice.

Choose a WAV reference voice.
1. Run start.bat. 2. Choose a 1–30 second WAV sample here. 3. Click Save Reference WAV. 4. Seed-VC's real-time window will open. 5. Select clone_input\reference.wav as the reference voice. 6. Select your microphone as Input. 7. Select Voicemeeter Input / your virtual cable as Output. 8. Start Voice Conversion. This is speech-to-speech conversion. There is no STT, LLM, or TTS in this app.
