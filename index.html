Live pipeline
Waiting for microphone…

The browser captures audio continuously. Each short audio window is converted by the OpenVoice V2 tone-color converter, then resampled from 22.05 kHz to the selected output rate and queued into one persistent AudioContext. This avoids opening and closing an audio device for every chunk.

First launch

The page downloads the quantized OpenVoice V2 ONNX models from Hugging Face: about 43 MB total. They run locally in your browser with ONNX Runtime Web; your microphone/reference audio is not sent to a voice server. Chrome/Edge WebGPU is attempted first, with WASM fallback. ONNX Runtime Web supports browser inference and WebGPU on current Chromium builds.

Important for VRChat

Select the Voicemeeter virtual input/output that VRChat uses. The converted signal is generated as normal audio; VRChat receives it through the Windows/Voicemeeter microphone path, not through this page directly.
