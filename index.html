🎙 Browser RVC Voice Changer

No VCClient. No Python. No Electron. The conversion engine runs in Chrome using WebAssembly/WebGPU.

Audio path
Microphone → browser RVC → selected output → VRChat

RVC needs a trained target-voice model. A reference WAV by itself cannot be turned into a target RVC voice inside this browser runtime.

Ready — waiting for a voice model.
What this test is checking
  • Chrome microphone capture
  • Local RVC inference
  • WebGPU acceleration for the feature/pitch stages when available
  • Direct browser audio output

Important: the current browser RVC runtime is an experimental/offline-oriented pipeline, not a finished low-latency live converter. This first version deliberately tests the browser engine before we build a continuous chunk pipeline around it.
