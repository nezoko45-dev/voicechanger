VoiceChanger

Simple local voice changer: microphone → OpenVoice V2 ONNX → Voicemeeter

Starting...
Audio path
Microphone → WASAPI input → OpenVoice V2 ONNX Runtime → WASAPI output → Voicemeeter Input

In Voicemeeter, route the virtual input to the bus you want. For VRChat, use the corresponding Voicemeeter Output recording device as your microphone.

Load a reference WAV, select your microphone and Voicemeeter output, then Start.
