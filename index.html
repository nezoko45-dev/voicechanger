🎙 Local Female Voice Repeater

Chrome microphone → local Hugging Face Kokoro TTS running in the browser → selected speaker. No Deepgram, DLL, server, or cloud TTS.

Press LOAD VOICE. The first load downloads the Kokoro ONNX model and caches it in the browser.
Model: onnx-community/Kokoro-82M-v1.0-ONNX, using q8 browser inference. Kokoro is 82M parameters and provides multiple female English voices. The model is Apache-2.0. Speech recognition uses Chrome's Web Speech API; TTS inference runs locally in the browser after the model is cached.
