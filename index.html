🎙 Local Live Voice Changer

VoxShot has been removed. This app now uses a local real-time voice-conversion engine.

Audio path
Microphone → RVC/VCClient → virtual microphone → VRChat
Launcher
Run start_voicechanger.bat from this folder. It starts the local voice-conversion client.
VRChat
Set VRChat's microphone to the virtual output created by the voice changer.

✓ No Deepgram credits
✓ No VoxShot/WebGPU
✓ No Electron
✓ Continuous real-time conversion

Voice models are loaded by the local RVC client.
