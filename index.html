🎙️ Cloud Live Voice Changer

Real-time microphone voice conversion through Resemble Live VC. No Python, CUDA, or local RVC server required.
Ready — press Start Voice Changer.

Cloud activity

Setup: deploy this repo with Vercel and set RESEMBLE_API_KEY plus RESEMBLE_LIVE_VC_HOST as server-side environment variables. The API key is never sent to the browser. Your short-lived connection ticket is issued by /api/resemble-ticket.
