🎀 Local RVC Voice Changer

This page is now a simple front end for the local RVC engine. Your microphone audio stays on your Windows PC.

Audio path

🎤 Microphone → RVC → Voicemeeter / virtual cable → VRChat

First-time setup
  1. Run setup_rvc.bat.
  2. Put your RVC voice model in the local RVC package.
  3. Run start_rvc.bat.
  4. Select your microphone and output inside RVC.
  5. For VRChat, send RVC output to Voicemeeter and select that virtual device in VRChat.
RVC launcher is ready.
No Tone.js, Deepgram, Hugging Face speech-to-speech, WebSocket server, or cloud voice processing is used by this version.
