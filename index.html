🎙 Pocket TTS Voice Changer

Pure browser version — Chrome mic + Pocket TTS ONNX + custom WAV voice cloning. No local server or Python required.

Your WAV is the only voice used. No catalog voice fallback.
Generated audio is also streamed directly to the selected output device.
Choose your custom WAV, then press START. The first model load is cached by Chrome.
GitHub Pages hosts the UI. Pocket TTS inference runs inside a Web Worker using ONNX Runtime Web. Voice-cloning model assets are fetched by the browser and cached locally by Chrome.
