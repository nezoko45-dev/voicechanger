Finished utterances are sent to Aura 2 Amalthea and the returned audio is streamed back. Microphone frames are gated while TTS is playing to prevent feedback loops.

Important

This is a static browser app, so the key is held in the browser. Deepgram recommends short-lived tokens from a server for production browser apps. This build intentionally keeps the requested no-backend HTML setup.
