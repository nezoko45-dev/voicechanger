Deepgram → OpenVoice V2

Mic → Deepgram STT → Deepgram Aura TTS → local OpenVoice V2 tone conversion → Chrome audio.

Select a clean WAV reference and press Load voice.
—
The browser handles the microphone and both Deepgram WebSockets. OpenVoice V2 stays local and only receives the generated TTS audio plus your selected reference voice. Each utterance is buffered completely before conversion so the start/end of speech is not chopped.
