Flux Continuous Voice

Continuous microphone → Flux STT → Amalthea TTS → Chrome audio. No chunked stop/start listening.

Ready.
—

The listener remains connected while you talk and during silence. Flux STT detects each end-of-turn and the completed transcript is sent to the persistent Amalthea TTS stream. Audio is scheduled continuously to reduce gaps and chopping.

Note: Amalthea is a Filipino Aura-2 voice, not a Flux TTS voice. This build therefore uses Flux for continuous STT and Aura-2 Amalthea for the requested Filipino TTS voice.
