OpenRouter TTS Reader

GitHub Pages edition — no EXE or local server required. Open this page in desktop Chrome over HTTPS, allow microphone access, then start dictation. Speech is generated with OpenRouter and played in your browser.

Microphone access: This page is served over HTTPS, which allows Chrome to request microphone permission. Click “Start microphone dictation” and choose Allow when Chrome prompts. If you previously blocked it, use the site icon beside the address bar → Site settings → Microphone → Allow, then reload.

Your API key is kept only in this page's memory and is sent directly to OpenRouter when generating speech. It is not saved to GitHub or browser storage. Avoid using this on a shared computer.
