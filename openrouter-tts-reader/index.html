Voice Dictation & Neural Reader

Keep your existing microphone dictation. Upload a custom WAV once to create a private Fish Audio voice, then use that voice for natural read-aloud.

Microphone: Open this GitHub Pages site over HTTPS, click Start microphone dictation, and allow microphone access. For best results while reading aloud, use headphones so the microphone does not hear the computer's speaker.
Custom reference voice

Choose your own clean WAV recording. Fish Audio creates a private reusable voice ID from it. A clean 10–30 second sample is a good starting point; longer clean speech can help.

For secure API access, deploy the included API routes to a Vercel project and set FISH_AUDIO_API_KEY there. The key is never placed in this GitHub Pages page.

Ready. Open this page in Microsoft Edge, select a Microsoft voice, allow microphone access, then start dictation.

The voice list comes directly from Microsoft Edge and Windows. Microsoft online neural voices may appear after Edge finishes loading its voice service. If a voice is missing, Edge is not exposing it to this page.
