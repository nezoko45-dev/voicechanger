OpenRouter TTS Reader

Windows EXE + microphone dictation. The EXE generates and plays audio directly through the Windows output device you select below. Chrome handles microphone dictation and controls; audio does not play in the browser.

First: Run OpenRouterTTSHelper.exe and keep that window open. Enter your OpenRouter API key in the field below. Dictation uses Chrome's speech recognition.

The key stays in this page's memory and is sent to your local helper only when you generate speech. It is not saved to GitHub or browser storage. Clear it before closing the page if using a shared computer.

Allow microphone access. Keep this tab open while speaking.

Run OpenRouterTTSHelper.exe first, then start dictation or enter text.

Audio is played by the EXE through the selected Windows device (including Voicemeeter devices when available). Keep the EXE running.

Voice examples: Grok: eve, ara, rex, sal, leo. Voxtral: en_paul_neutral. MAI: en-US-Harper:MAI-Voice-2. The selected model and voice must be supported by your OpenRouter account.
