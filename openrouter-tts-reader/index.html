Chrome Voice Dictation & Reader

A browser-only voice page. Chrome handles microphone dictation and reads text aloud using voices available to Chrome on this computer. No EXE, API key, Python, or local server.

Microphone: Open this GitHub Pages site over HTTPS, click Start microphone dictation, and allow microphone access. For best results while reading aloud, use headphones so the microphone does not hear the computer's speaker.

Ready. Select a Chrome voice, allow microphone access, then start dictation.

The voice list is supplied by Chrome and Windows. If a voice does not appear, it is not currently exposed to this Chrome profile. Voices can load a moment after the page opens.
