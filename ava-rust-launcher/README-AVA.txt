AVA RUST VOICE CHANGER — WINDOWS PORTABLE PACKAGE

This package contains the official prebuilt vc-rs Windows ML GUI/CLI files plus a small launcher.
It does not require you to install Python or Rust.

START
1. Extract the entire ZIP to a normal folder (do not run from inside the ZIP).
2. Keep every DLL in the same folder as vc-gui.exe.
3. Double-click start-ava.bat.
4. In vc-rs Setup, choose your microphone and audio output.
5. Select a compatible RVC voice model, finish setup, then press Start.

INTEL GRAPHICS
This is the Windows ML build. Choose an available DirectML or CPU backend in Backend Details.
Intel OpenVINO options are experimental and may not appear on every PC. Your Intel UHD 730 may need CPU fallback.
Performance and latency depend on the driver, model, and settings.

REQUIRED WINDOWS COMPONENT
The upstream Windows ML package requires Microsoft Windows App SDK Runtime 2.1 or later.
If vc-gui.exe reports a missing Windows App SDK Runtime, install the matching runtime from:
https://learn.microsoft.com/en-us/windows/apps/windows-app-sdk/downloads

AVA VOICE MODEL
No Ava model is bundled. vc-rs requires a compatible RVC model (normally .onnx; supported RVC v2/F0 .pth checkpoints can be converted by the app).
A recording generated by Microsoft Edge Read Aloud is training audio, NOT a ready-to-use RVC model.
This package does not train or clone Ava automatically, and it does not guarantee an exact reproduction of Microsoft's proprietary voice.

VRCHAT ROUTING
Set vc-rs output to a virtual audio cable/playback endpoint, then select the paired recording endpoint as your VRChat microphone. Voicemeeter can be used for this routing.
