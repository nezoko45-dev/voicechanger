AVA MODEL PLACEHOLDER

Place your compatible, legally obtained Ava-style RVC model in this folder.
The model should be in a format supported by vc-rs (preferably ONNX; supported RVC v2/F0 PTH checkpoints may be converted in the GUI).

An Edge-generated WAV is not itself an RVC model. Creating a model from recordings requires a separate training workflow and sufficient clean, permitted training data.

No Microsoft Ava model is included or implied.
