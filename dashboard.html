Setup

1
Open Zalt Text to Speech

Click Open Zalt Text to Speech and select the voice you want to use.

2
Click Start once

Allow microphone access. Speak normally; when you pause, the extension fills the text field and clicks Generate Speech on the webpage.

3
Route generated audio to VRChat

Set Windows playback output to your virtual audio cable, then select that cable's corresponding input as VRChat's microphone.

4
Keep the Zalt Text to Speech tab open

The Zalt Text to Speech tab must remain open. The extension waits for the conversion button to finish before sending the next phrase.

What this does

This version automates the Zalt Text to Speech website UI. The Zalt downloads its speech model on first use; wait for the page to finish loading before dictating, so longer phrases may need to be shortened. The first run should be tested because website layout changes can affect button detection.
