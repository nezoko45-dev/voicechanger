ElevenLabs Call Autoclicker

Automatically restart your ElevenLabs agent calls while you stay in VRChat.

Call restart monitor

Open your ElevenLabs agent page. When a visible, enabled “Start a call” button appears, the extension clicks it once. It waits for the button to disappear before it can click the next appearance.

Stopped. Open your ElevenLabs agent page first.

Setup

1
Open your ElevenLabs agent

Use the Open ElevenLabs button, then navigate to the page where your agent's “Start a call” button appears.

2
Start the autoclicker

Enable the monitor here. Keep the agent tab open while you switch to VRChat.

3
Test a call ending

When “Start a call” reappears, the extension should click it once. Chrome may throttle background tabs, and page redesigns or agent limits can prevent a restart.
