OPENVOICE V2 CLONE-ONLY

Clone workflow:
1. Select or prepare a reference .WAV.
2. Drag the .WAV file directly onto clone.bat.
3. OpenVoice V2 extracts the reusable voice embedding.
4. The result is saved to:
   cloned_voice\voice_embedding.pth

There is no web server in this project.
There is no browser-to-local-server connection.
The browser page is only a simple file picker/instruction screen.
